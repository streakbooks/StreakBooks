## LinkBooks original improvements

1. **Accounting-safe chat** — message text cannot post, pay or approve; formal actions only.  
2. **Visibility modes** — internal vs external threads on the same record without accidental leak.  
3. **Unified multi-audience platform** — one schema for members, portals, firms and advisors.  
4. **Action Center integration** — collaboration items join the same actionable inbox.  
5. **Outbox + durable history** — realtime is notification, not storage.  
6. **Employee lifecycle hooks** — membership re-evaluation on HR status changes.  
7. **Cross-client firm isolation** — org-context evaluation every request.
