# Competitor feature matrix

Reviewed public vendor documentation on 2026-11-17. These are functional references, not interface templates. Feature availability varies by country, plan, hardware and merchant contract. No vendor hardware or merchant flow was exercised. Eight vendors now have readable official source evidence. Direct shell retrieval initially failed for Lightspeed/Clover; official search-index and documentation access resolved those research gaps in batch 2. No hardware or merchant integration has been exercised.

Cashier speed: prioritize explicit SKU/name lookup, keyboard submission, large Add/Remove targets and stable cart calculations. Offline acceptance is a separate provider/device decision, even where vendors advertise offline features. Refunds, drawer management and settlements must preserve accounting origins. Loyalty/gift cards require both customer identity and liability/reward ledgers. All UX will use StreakBooks workspace tokens and original layouts.
