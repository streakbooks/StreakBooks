# Competitor feature matrix

Reviewed public vendor documentation on 2026-11-17. These are functional references, not interface templates. Feature availability varies by country, plan, hardware and merchant contract. No vendor hardware or merchant flow was exercised. Six sources yielded readable feature text; Lightspeed blocked retrieval (403) and Clover yielded an app shell. Their rows are research gaps, not verified feature claims. Eight-platform research acceptance is therefore still incomplete.

Cashier speed: prioritize explicit SKU/name lookup, keyboard submission, large Add/Remove targets and stable cart calculations. Offline acceptance is a separate provider/device decision, even where vendors advertise offline features. Refunds, drawer management and settlements must preserve accounting origins. Loyalty/gift cards require both customer identity and liability/reward ledgers. All UX will use LinkBooks workspace tokens and original layouts.
